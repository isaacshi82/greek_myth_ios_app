## Focus: AI image pipeline + Titan/Olympian character art

### Wired up the Gemini image API (`scripts/gen_art.py`)
- Confirmed direct image generation works from the dev environment via the Gemini API
  (`gemini-2.5-flash-image` for busts, `gemini-3-pro-image` @ 2K for scenes).
- `scripts/gen_art.py`: prompt → image → optional auto-import through `add-asset.sh`.
  - Reads `GEMINI_API_KEY` from the environment — **no key stored in the repo**.
  - Flags: `--ref` (one or more reference images for character consistency),
    `--name`/`--type` (import), `--aspect` (e.g. 16:9), `--model`, `--size` (1K/2K/4K).
- Cost is ~$0.04/image on flash, ~$0.13/image on pro-2K. Whole Titan set ≈ $0.50.

  in Google AI Studio.

### chapter1-04 (Titan lineup) — attempted, then PARKED
- Goal: make the background Titans in chapter1-04 match the new character designs.
- Tried two approaches, both worse than the original:
  1. **Iterative one-by-one add** (build the scene up figure by figure): degraded Cronus
     on each re-render, scattered the line, and dropped figures.
  2. **Single-shot repaint** of the original: figures came out old and samey (one bearded

  one crowd scene. **Decision: keep the original chapter1-04.** Character consistency lives
  in the library/portraits, where it actually matters; the panel just needs to read as
  "a mighty host," which the original does.

## Discussed: ComfyUI on a cloud GPU (next capability)
- ComfyUI **can** do consistent multi-character group scenes via **regional/area
  conditioning + IPAdapter (per-character references) + ControlNet OpenPose**.
- Local is impractical here (M1 Pro, but only ~37 GB free disk; Flux needs ~40–60 GB).
- **Plan: cloud GPU via RunPod** (one-click ComfyUI+Flux template, ~$0.22–0.39/hr, pay per
  second, persistent volume for the model). See `docs/comfyui-runpod-checklist.md` and
  `workflows/titans-group-scene.json`.
- **Style-match caveat:** Flux won't reproduce Gemini's "Hades × manga" look exactly — a
  lone ComfyUI panel could clash; matching well means training a small **style LoRA** on
  the existing panels. So ComfyUI pays off as a deliberate capability, not a one-off.

## Things Isaac Should Know
- `scripts/gen_art.py` is our reusable "make art from a prompt" tool. References
  (`--ref`) are how you keep a character looking the same across pictures.
- Two art "generations" on purpose: **Titans = muted/old**, **Olympians = bright/new**.
  The visual contrast reinforces the story.
- Sometimes the right engineering call is to **stop** — chapter1-04 was better left alone
  than "fixed" into something worse.
